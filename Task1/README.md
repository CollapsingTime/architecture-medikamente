# Task 1. Анализ безопасности системы

## Состав решения

| Файл | Содержание |
|---|---|
| `AM_C4_diagram_as_is.drawio` | Исходная C4-диаграмма текущего состояния |
| `DFD_as-is.drawio` | 8 отдельных DFD-диаграмм As-Is на каждый процесс: P1 регистрация, P2 запись, P3 прием и медкарта, P4 анализы и лаборатория, P5 оплата и учет, P6 кадры и зарплата, P7 склад и ТМЦ, P8 аналитика BI/ML |

| `Problem_areas.md` | Инвентарь конфиденциальных данных D-01–D-10, аудит соответствия процессов практикам безопасности, реестр проблемных зон R-01–R-15 |
